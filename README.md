# Bank-analysis

Bank Loan Analytics is a comprehensive data analysis project designed to evaluate and understand a bank’s loan portfolio using modern analytical tools like SQL, Excel, Power BI, and Tableau. The project transforms raw loan data into meaningful insights that help financial institutions improve their lending strategies, manage risks more effectively, and understand customer behavior in depth.

This project covers detailed analysis on:

Loan distribution across years, states, and income categories

Customer loan purposes (debt consolidation, credit card, home improvement, etc.)

Home ownership impact on loan amounts

Loan verification status and its effect on default rates

Loan grades and sub-grades

Default vs completed loan comparison

Monthly and yearly loan trends

All dashboards offer interactive and visual representations that help stakeholders quickly interpret the bank's loan performance and identify key risk areas. SQL queries were used to clean, process, and extract insights from the dataset, while visual dashboards provide an intuitive storytelling layer.

The goal of this project is to help banks make data-driven decisions, improve risk assessment, and optimize lending strategies based on customer trends and financial behavior.
